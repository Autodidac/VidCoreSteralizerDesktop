Library storage

Favorites are an overlay and no longer replace a title's category. Edit/Save can also attach the exact next video in a series. Create lists directly inside Edit/Save; empty lists persist until you explicitly delete them, and saving switches Library to the destination list. Favorites, lists, notes, watched state, Continue Watching, and history use IndexedDB when available. In the native player, browser storage and cache stay in the portable data folder beside the executable. The native player creates data/artwork/category/title folders; drop several JPG, PNG, WebP, GIF, BMP, or AVIF images into a title folder and one is selected randomly for that launch. Those user-owned files are never downloaded or deleted by the player. JSON export stores provider categories once, then uses compact provider indexes per title. Version 1 backups with full provider URLs remain import-compatible.

Exact playback position is unavailable because the provider frame is cross-origin. Continue Watching records played titles and manual completion state.

Native popup shield

Native extension loading is disabled in this security rollback.

The C++ host cancels WebView2 new-window requests and top-level navigation hijacks. A document-created guard also blocks window.open, target-blank links, external click redirects, middle-click navigation, and external form submissions inside every frame.

This prevents popup tabs and window hijacks. Native browser-extension loading was removed after the v0.2.16 Microsoft Defender detection. Provider and YouTube filtering remains limited to blocker support supplied by the browser or provider; do not restore or allowlist the blocked v0.2.16 binary.
